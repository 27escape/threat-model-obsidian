# Threat Modelling 0.3.2 — release notes

A tidier bar above each diagram, a *Tools* menu that gets the model out of Obsidian the way the web app does, and icon suggestions as you type.

## New

- **Tools menu.** In Obsidian, the menu at the end of each diagram's bar holds everything that isn't a view: *Edit* (with a tick while it is on, and the *Tools* button highlighted), *Report*, and the web app's ways to get the model out: *Download as .threat file* (from a note) or *Copy as code block* (from a `.threat` file), *Copy a link to share*, *Open in the web editor*, *Download picture* (SVG or PNG, of the diagram shown, at its own size) and *Download threat register* (CSV). Downloads go through your computer's save dialog; Obsidian on a phone or tablet can't download, so use the link or the web editor there.
- **Icon suggestions.** Start typing in the *Icon* field of the Threat model editor (Obsidian and the web app) and matching icons show with their names; the icon the element's technology would give comes first.

## Changed

- **A calmer bar above each diagram.** The model's title is on its own line; under it the scenario list (when there are scenarios), the view list and the level list sit at the left, and the *Threats*, *Zones* and *Compact* switches with the *Tools* menu (or *Report* in the web app) sit together at the right, even when the bar wraps. A long scenario name is cut short in the list, with the full name when you hover over it.
- **Zoom buttons float over the diagram** at its top right, faint until you hover over the diagram (clearer on a touchscreen), instead of taking a row of their own.
- The *Edit* and *Report* buttons have moved into the *Tools* menu.
- The GitHub workflows run on Node 24.

## Requirements

Obsidian 1.15 or later. Works on desktop and mobile.

## Privacy

Unchanged: the plugin makes no network requests, and writes to a note only when you save a report or save a change in the Threat model editor (and then only inside that model's code block). Downloads are saved only where you choose in the save dialog.
