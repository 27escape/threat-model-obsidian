# Threat Modelling 0.3.1 — release notes

Scenarios on every view, zoom buttons on the diagrams, nested zones rated as they really are, and the web app as a page to download.

## New

- **Scenarios on every view.** When a model has scenarios, a scenario list comes first in the diagram's bar, before the list of views. *All scenarios* (where every diagram opens) shows the whole model; choose a scenario and the Structure and Data flow views show only its flows, the elements at their ends (with the systems and containers around them) and their zones, and the threat register and findings under the diagram follow it. The choice is shared by the three views, so you can look at one journey each way. Flows keep their numbers, and clicking a threat ID or (with *Edit* on) a box still finds the right thing. A model with no scenarios has no list.
- **Zoom buttons** above each diagram, at its right: zoom out, the zoom (click it to go back to the diagram as first drawn), zoom in, and *Fit*, which fits the whole diagram in the width and height of the pane, handy for a long one. The zoom is kept as you switch views or scenarios, and when the diagram is redrawn after an edit.
- **Nested zones rated as they really are.** A flow between two zones that are both inside another (two regions of one AWS account, say) still crosses a boundary, but its findings are now a step less serious than those of a flow going out of or into a zone altogether, and say which zone it stays inside ("between zones inside AWS (private)"). The report counts these crossings separately and lists them after the others, with a *Stays inside* column. Models without nested zones are rated and reported as before. The language reference has an example.
- **The web app to keep:** each release now has the web app attached as `threat-modelling.html`, one file to download and open in a browser, offline. A clone of the repository has it too, as `web/threat-modelling.html`. Opened from your computer, the examples and diagrams work, though some browsers won't let the page save your own models.
- **The AI skill writes scenarios.** `skills/threat-model/` now asks about the main journeys and writes a scenario for each (suggesting the obvious ones when you name none, marked as suggestions), reads numbered arrows on a picture as a scenario, and models regions or VPCs inside a cloud account as nested zones.

## Changed

- The web app turns off Pele's own small zoom buttons on its diagrams, as the new zoom buttons do the job (they stay on the report shown in the page).
- The README's *Privacy* section now covers the Threat model editor and *Open in the web editor*.

## Requirements

Obsidian 1.15 or later. Works on desktop and mobile.

## Privacy

Unchanged: the plugin makes no network requests, and writes to a note only when you save a report or save a change in the Threat model editor (and then only inside that model's code block).
