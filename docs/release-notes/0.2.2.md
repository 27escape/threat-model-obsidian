# Threat Modelling 0.2.2 — release notes

A web app, an AI skill for drafting threat models, and two small fixes to the plugin.

## New

- **The web app:** https://27escape.github.io/threat-model-obsidian/. The same models, views, threat register and report as the plugin, in a web page, for trying the language without Obsidian or for people who don't use it. It has examples to open and change, and keeps your own models in your browser, each under a name you choose. *Download* saves a model as a `.threat` file for your vault, and *Copy as code block* copies it to paste into a note. *Report* downloads the report as Markdown. Nothing leaves your browser: the page makes no connections and works offline once loaded. Your models stay in that one browser on that device, so *Download* is the backup; the page's *About* says more.
- **Drafting a model with an AI.** [`skills/threat-model/`](https://github.com/27escape/threat-model-obsidian/tree/main/skills/threat-model) is a skill (instructions for an AI such as Claude) that drafts a model from a photo of a whiteboard or diagram, or from you describing the system.
  - From a picture, it lists what it couldn't read (unlabelled arrows, boxes that may or may not be trust boundaries, hand-writing) and asks about it rather than guessing.
  - From a description, it asks about the system one topic at a time: users, parts, third parties, zones, flows, sensitive data and key journeys.
  - It plays the system back in plain English for you to correct before writing anything.
  - It suggests threats with STRIDE per element, each rated by likelihood and impact with its reasoning, and labelled "(suggested)" for you to review.
  - The model is marked as a draft, and starts with a comment saying where it came from and what was assumed.
- To use it with Claude, add it as a skill in Claude's settings, or copy the folder into a project's `.claude/skills/` for Claude Code. Other AI tools can be given `SKILL.md` as instructions. `examples/from-a-picture.md` walks through a whiteboard photo from start to finish.

## Fixed

- The example model the *Insert an example threat model* command adds had two warnings (it used the old `score`). It is now rated by likelihood and impact, with protocols on its flows.
- Lucide, the icon set Obsidian uses, has renamed two icons the plugin chooses itself: `shield-alert` (untrusted zones) is now `shield-exclamation-point`, and `building-2` (external systems) is `building-complex`. The plugin now tries both names, so the icons show whichever copy of Lucide your Obsidian has.

## Requirements

Obsidian 1.15 or later. Works on desktop and mobile.

## Privacy

Unchanged: the plugin makes no network requests, and writes a file only when you ask. The skill runs in whichever AI tool you use it with, not in Obsidian.
