# Threat Modelling 0.2.1 — release notes

A fix to the settings page, and a small change to the icon.

## Fixed

- The settings page showed only *First view*, *First C4 level* and *Show warnings*: the rest (*Default icons*, and the report settings) were missing in 0.2.0. They are all back.

## Changed

- The tab of a `.threat` file now has the plugin's own icon, `shield-half`, instead of `shield-alert`. Since 0.2.0, `shield-alert` marks an untrusted zone in the Data flow view, so it now has that one meaning.

## Requirements

Obsidian 1.15 or later. Works on desktop and mobile.

## Privacy

Unchanged: no network requests, and a file is written only when you ask.
