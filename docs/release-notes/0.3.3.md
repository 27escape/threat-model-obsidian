# Threat Modelling 0.3.3 — release notes

A small release: the Internet banking example gets scenarios.

## Changed

- **The Internet banking example has two scenarios**, *Web banking* (the single-page application) and *Mobile banking* (the mobile app). Each signs in, through the security component to the database, then fetches the accounts summary, through the facade to the mainframe. Choose one in the scenario list to see that client's path and its threats on every view. The example is in the sample vault and in the web app.

## Requirements

Obsidian 1.15 or later. Works on desktop and mobile.

## Privacy

Unchanged: the plugin makes no network requests, and writes to a note only when you save a report or save a change in the Threat model editor (and then only inside that model's code block).
